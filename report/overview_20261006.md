# 图文融合检索 + listwise 推理重排：总报告

数据集 MMDocIR，文档内检索。所有模型经 SiliconFlow API 调用，无本地权重。
本文数字取自 `output/` 下的落盘产物；各阶段的完整表格见：

- `retriever/fusion_retrieval_20261006.md`：第一部分，图文融合检索
- `reranker/listwise_rerank_20261007.md`：第二部分，listwise 推理重排
- `reranker/pointwise_baseline_20261007.md`：第二部分，pointwise 对照基线

---

## 1. 任务与数据

| 阶段 | 任务 | 输入 | 输出 |
|---|---|---|---|
| 第一部分 | 图文融合检索 | query + 文档内全部页面 | Top-K 候选页 |
| 第二部分 | listwise 推理重排 | query + Top-10 候选（页面图像 + OCR 文本） | 完整排序 + 逐候选证据坐标 / 类型 / 档位 / 理由 |

数据统计（`output/common/dataset/mmdocir/stats.json`）：

| 项 | 值 |
|---|---:|
| query 数 / 页面数 / 文档数 | 1658 / 20395 / 313 |
| 检索口径 | 文档内 |
| 平均候选页 / 平均相关页 | 64.9 / 1.271 |
| 有证据框的 query | 1657（99.94%） |
| 空 OCR 页占比 | 0.89% |
| domain 数 | 10 |

字段：`qid`、`query`、`answer`、`group`（domain）、`content_types`、`gt_pages`、`gt_rel`（恒为 1）、`gt_boxes`（归一化 bbox）、`cand_span`（候选页闭区间 = 所属文档的页范围）。
页面表：`page_uid`、`doc_id`、`page_no`、`ocr_text`、`img_w`、`img_h`。`page_uid` 同时是 `MMDocIR_pages.parquet` 的物理行号，页面图像按行号流式读取。
页面文本仅使用 OCR；布局 bbox 仅作为定位评测的真值，不读取 `MMDocIR_layouts.parquet`。

两阶段之间的唯一接口为 `topk_candidates.jsonl`。

---

## 2. 方法

### 2.1 第一部分：图文融合检索

1. 页面图像与页面 OCR 文本分别由 `Qwen/Qwen3-VL-Embedding-8B` 编码，与 query 嵌入作内积；
2. 每路分数在 query 的候选集内做 sigmoid + z-score 校准；
3. 凸组合 $s = \alpha\hat{s}_{img} + (1-\alpha)\hat{s}_{txt}$，α 以 Recall@5 为目标网格搜索；
4. 自适应加权：线性分类器根据 query 嵌入判断意图（视觉类 / 文本表格类），两类各用一个 α（$\alpha_{vis} = 0.91$，$\alpha_{txt} = 0.47$）；
5. 以 5 折、按文档分折的 held-out 协议评估自适应加权，避免同一文档的 query 跨折。

### 2.2 第二部分：listwise 推理重排

一次调用把 Top-10 候选的「编号 + OCR 文本 + 页面图像」按序交给 `Qwen/Qwen3.8-27B`（思考模式开启），模型逐候选输出证据坐标、类型、相关度档位与理由，最后输出覆盖全部候选的完整排序；排序不与检索分加权。
每个候选对象的键序固定为 `id → evidence_boxes → evidence_type → relevance → reason`。输出经确定性合法化后恒为全排列。
对照基线为 `Qwen/Qwen3-VL-Reranker-8B` 的 pointwise 重排，同样不与检索分融合。

## 3. 结果

### 3.1 第一部分（micro，%）

| 指标 | 纯文本 | 纯图像 | 融合（in-sample） |
|---|---:|---:|---:|
| Recall@1 | 50.37 | 54.99 | 55.37 |
| Recall@5 | 79.68 | 83.40 | 84.83 |
| Recall@10 | 88.17 | 90.27 | 91.24 |
| NDCG@10 | 71.89 | 75.75 | 76.49 |

Top-50 候选的 Recall@20 / Recall@50 为 95.40 / 99.10。

自适应加权（5 折 held-out，Recall@5）：

| 方案 | Recall@5 | Δ vs 固定 α |
|---|---:|---:|
| 固定 α | 83.52 | — |
| 意图预测 → 两档 α | 84.32 | +0.81 |
| 真实标签 → 两档 α（上界参考） | 84.71 | +1.19 |

意图分类器 held-out 准确率 0.802（多数类基线 0.700）。

### 3.2 第二部分（Top-10，全量 1658 query，micro，%）

| 指标 | 检索 | pointwise | listwise |
|---|---:|---:|---:|
| Recall@1 | 55.37 | 66.60 | 71.03 |
| Recall@3 | 77.15 | 83.97 | 87.26 |
| Recall@5 | 84.83 | 88.00 | 89.77 |
| NDCG@10 | 76.49 | 82.82 | 85.81 |
| MRR@10 | 73.33 | 81.46 | 85.47 |

- Recall@10 三者相同（91.24）；111 条 query 的相关页不在 Top-10 内；
- 相关页最佳名次下降的 query：pointwise 143 条（9.2%），listwise 64 条（4.1%）；
- listwise 的 NDCG@10 在 10 个 domain 上均高于 pointwise，Financial report 与 Academic paper 的 Recall@1 分别高 7.73 与 7.76 pp；
- 输出格式：1654 / 1658 条解析成功，标签合法率 100%，排序全部取自 `<ranking>`；另 4 条调用失败，按检索序计入指标；
- 定位（1881 个可评页）：mean IoU 0.304，containment@0.5 为 60.6%，预测框面积为 GT 的 0.543 倍；
- 资源：每 query prompt 7267 token、completion 4550 token（其中 reasoning 3902）。

## 4. 局限

- 第一部分：held-out 仅使用单一分折种子；最终配置为全量拟合；图像与文本两路由同一嵌入模型编码；
- 第二部分：位置偏置未分离（候选始终按检索序呈现）；10.3% 的请求思考量触及预算上限；4 条调用失败；单模态消融未运行；
- 两部分的对照均为点估计，未做显著性检验；仅使用单一数据集与单一生成模型。

## 5. 复现

```bash
cd code && pip install -r requirements.txt
# code/.env：SILICONFLOW_API_KEY / SILICONFLOW_BASE_URL / SILICONFLOW_MODEL=Qwen/Qwen3.8-27B

# 第一部分
python -m common.dataset
python -m retriever.encode --mode query,page_text,page_image --workers 8
python -m retriever.search --topk 50 --adaptive        # 一键：bash run_retrieval.sh

# 第二部分（默认参数即本报告配置）
python -m reranker.prepare --topk 10 --limit 0 --max_side 896
python -m reranker.rerank --topk 10 --limit 0 --workers 24
python -m reranker.rerank_api --topk 10 --limit 0      # 一键：bash run_rerank.sh
```

本节命令记录当时的实现。当前目录结构、参数与产物说明见[项目 README](../README.md)。
