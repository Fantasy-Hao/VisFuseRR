# 第一部分：图文融合检索

| 项 | 值 |
|---|---|
| 数据集 | MMDocIR，文档内检索：1658 query / 20395 页 / 313 文档 |
| 平均候选页 / 平均相关页 | 64.9 / 1.271（二值相关度） |
| 表示 | `Qwen/Qwen3-VL-Embedding-8B`，4096 维，L2 归一化，内积相似度；query、页面 OCR 文本、页面图像分别编码，不加指令前缀 |
| 指标 | Recall / Precision / NDCG / MAP / MRR @1,3,5,10；micro 为全 query 平均，macro 为 10 个 domain 的均值 |
| 产物 | `output/retriever/mmdocir/Qwen3VLEmb8B/`（`encode/`、`retrieval/`） |

指标定义：Precision@K 的分母为实际返回的候选数；NDCG 增益为 2^rel − 1（相关度恒为 1，等价二值 NDCG）；
MAP@K 的分母取 min(|GT|, K)。K = 1 时 Precision、NDCG、MAP、MRR 相等。

## 1. 方法

### 1.1 查询级校准

对每条 query 的每一路候选页内积分数 s，先作 sigmoid，再在该 query 的候选集内作 z-score：

$$
\hat{s} = \frac{\sigma(s) - \mu_{\sigma(s)}}{\mathrm{std}\big(\sigma(s)\big)}, \qquad \sigma(s) = \frac{1}{1 + e^{-s}}
$$

标准差小于 $10^{-12}$ 时输出全零。

### 1.2 凸组合融合与权重搜索

$$
s(q, p) = \alpha\,\hat{s}_{img}(q, p) + (1 - \alpha)\,\hat{s}_{txt}(q, p)
$$

α 先在 [0, 1] 上以 0.05 为步长粗搜，再在最优点 ±0.05 内以 0.01 为步长细搜；目标为 Recall@5（micro）。

### 1.3 基于 query 意图的自适应加权

$$
\alpha(q) = \begin{cases}
\alpha_{vis}, & w^\top e_q + b > 0 \\
\alpha_{txt}, & \text{otherwise}
\end{cases}
$$

- 意图标签：`content_types` 的首个类型属于 {Figure, Chart, multimodal-f, Generalized-text (Layout)} 记为视觉类（占 30.0%），其余为文本 / 表格类。标签仅用于训练。
- 分类器：以 query 嵌入为输入的线性分类器，±1 目标岭回归，$\lambda = 1.0$，参数量 4097；推理时仅需 query 嵌入。
- 两档 α：按意图标签分组，各组搜索使 Recall@5 最大的 α；组样本数不足 30 时取全局 $\alpha_0$。最终配置按全量数据的真实标签分组；held-out 评测中按训练折上分类器的预测标签分组，与推理条件一致。
- $\alpha_{vis} = \alpha_{txt}$ 或自适应关闭时，退化为固定权重。
- 软插值变体：$\alpha(q) = \mathrm{clip}\big(\alpha_0 + A\,(2\sigma(3m_q) - 1),\,0,\,1\big)$，$m_q$ 为分类器间隔，$A \in \{0, 0.05, \dots, 0.40\}$ 在训练折上选取。

### 1.4 按文档分折的 held-out 协议

1. 以文档（`cand_span`）为单位分折，同一文档的 query 位于同一折，避免页面分布跨折泄漏；
2. 种子 42 打乱文档顺序后，按文档 query 数降序依次放入当前 query 总数最少的折；5 折的评测 query 数为 332 / 332 / 332 / 331 / 331；
3. 每折内：搜索 $\alpha_0$；按真实标签分组搜索两档 α（上界参考）；训练分类器；按训练折预测标签分组重搜两档 α；评测折上以预测标签确定 α；
4. 仅当 held-out 增益为正时，最终候选才采用自适应权重。

最终配置（$\alpha_{vis} = 0.91$，$\alpha_{txt} = 0.47$，分类器）在全量 1658 条上拟合，其指标为 in-sample 数值；泛化结论以 §2.3 的 held-out 为准。

## 3. 局限

- 融合相对最优单路的增益较小（Recall@5 +1.42 pp，in-sample）；固定权重曲线在 α ∈ [0.50, 0.85] 内平坦，$\alpha_0$ 的折间标准差为 0.130。
- 自适应加权的 held-out 增益为 +0.81 pp；in-sample 的逐 query oracle（87.86）仍明显更高，但低于 Recall@50（99.10），仅调节图文权重无法覆盖该差距。
- held-out 仅使用单一分折种子（42），未做显著性检验；最终配置为全量拟合；图像与文本两路由同一嵌入模型编码；仅在单一数据集上评估。
